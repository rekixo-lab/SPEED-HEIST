# SPEED-HEIST Unity Project

Open this `Game/` directory in Unity Hub with Unity **6000.3.27f1**. On first import, run **Tools > SPEED-HEIST > Generate Starter Scene**, then Play. To build: **Tools > SPEED-HEIST > Build Android Test APK** after installing Android Build Support.

These scripts and generation tools are checked in; the resulting Unity scene/assets and APK require Unity Editor on the development machine and have not been compiled in this environment. See `../docs/LOCAL_UNITY_SETUP.md`.
